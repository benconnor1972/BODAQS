# BODAQS Desktop 0.3.1-beta Release Notes

BODAQS Desktop `0.3.1-beta` is a macOS maintenance release that fixes context
menus in the Import Manager.

## Fixed

- Right-click menus now open correctly on the Import Manager's Sources and
  Libraries tables on macOS.
- Control-click is also supported as the standard macOS context-menu gesture.

## Component Versions

- BODAQS Desktop bundle: `0.3.1-beta`
- BODAQS Import Manager: `0.1.10-beta`
- BODAQS Library Service: `0.2.0-beta`
- BODAQS Workbench: `0.2.0-beta`

## Downloads

This maintenance release is distributed for macOS only:

- `BODAQS-Import-Manager-0.3.1-beta-macos-arm64.dmg` — Apple silicon Macs
- `BODAQS-Import-Manager-0.3.1-beta-macos-x64.dmg` — Intel Macs

Windows and Linux packages are not included in this release. Users on those
platforms can continue using BODAQS Desktop `0.3.0-beta`.
