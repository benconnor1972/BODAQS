# BODAQS Releases

This page is a human-friendly index for BODAQS downloads. GitHub's Releases
page is chronological, so this file groups releases by component.

Repository releases page:

- https://github.com/benconnor1972/BODAQS/releases

## BODAQS Desktop

Bundles the Import Manager, BODAQS Workbench analysis app, library service and optional demonstration library into one Windows install package.

Latest release:

- [BODAQS Desktop 0.2.1-beta](https://github.com/benconnor1972/BODAQS/releases/tag/Desktop-v0.2.1-beta)

## Firmware

ESP32 logger firmware for BODAQS devices.

Latest release:

- [BODAQS Firmware 0.5.0](https://github.com/benconnor1972/BODAQS/releases/tag/firmware-v0.5.0)

## Analysis Package

Python notebooks and the `bodaqs_analysis` module package for preprocessing,
browsing, analysing, and exporting BODAQS data.

Latest release:

- [BODAQS Analysis Package 0.3.0](https://github.com/benconnor1972/BODAQS/releases/tag/analysis-v0.3.0)

**Note: this release is a long way out of date**
