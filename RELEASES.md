# BODAQS Releases

This page is a human-friendly index for BODAQS downloads. GitHub's Releases
page is chronological, so this file groups releases by component.

Repository releases page:

- https://github.com/benconnor1972/BODAQS/releases

## Import Manager

Windows desktop app for creating BODAQS libraries and import sources, importing
logger files, and running the local preprocessing workflow.

Latest alpha:

- [BODAQS Import Manager 0.1.4-beta](https://github.com/benconnor1972/BODAQS/releases/tag/import-manager-v0.1.4-beta)

## Firmware

ESP32 logger firmware for BODAQS devices.

Latest release:

- [BODAQS Firmware 0.4.0](https://github.com/benconnor1972/BODAQS/releases/tag/firmware-v0.4.0)

## Analysis Package

Python notebooks and the `bodaqs_analysis` module package for preprocessing,
browsing, analysing, and exporting BODAQS data.

Latest release:

- [BODAQS Analysis Package 0.3.0](https://github.com/benconnor1972/BODAQS/releases/tag/analysis-v0.3.0)
