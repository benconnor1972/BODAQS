The **BODAQS A8** mountain bike data logger is a powerful data acquisition tool that can be sourced and built by the end user. It supports a range of sensors and has analysis software for Windows, MacOS and Linux.

All parts of the design are open source and can be used free of charge, including commercially.

Explore this website for details on sourcing, building, installing and using a BODAQS A8 data logger.
