<Lede>
The ESP32 microcontroller on the PCB needs firmware installed ("flashed"). In addition, the logger needs a configuration file added to its MicroSD card to operate correctly.
</Lede>

## Flashing the firmware

#### Downloading the firmware binaries


<Flag src="/src/assets/pics/logger-build-guide/flash-1.png" alt="OLED-3E">
Go to the 'releases' page in the BODAQS github repository [here](https://github.com/benconnor1972/BODAQS/releases) and find 
the latest firmware release. The releases list includes releases for logger firmware, application software and other things 
besides. We are interested in *firmware releases*.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-2.png" alt="flash 2">
Scroll to the bottom of the release section and download the three `.bin` files for the A8 / RC3 logger.
</Flag>



<Aside type={"note"} title="Which binaries do I need?">
A complete set of binaries is three files: a bootloader, a partitions table and the application firmware itself. The **first time** you flash your logger, you need to flash **all three files**. If you update the firmware later, you will generally only need to flash the application firmware.

The firmware for the A8 logger might be labelled 'RC3' instead of 'A8'. RC3 stands for 'Release Candidate 3' - the last test version of the A8 board before its 'official' release. It works just the same.
</Aside>

<Flag src="/src/assets/pics/logger-build-guide/flash-3.png" alt="flash 3">
Find the `Flash addresses` section in the release notes. Note the addresses for each `.bin` file. 
</Flag>

#### Option 1: Browser flasher for Windows users

<Aside type="note" title="Chromium only">The ESPTool requires a chromium-based web browser such as Google Chrome, Microsoft Edge, or
  Brave</Aside>

This is the easiest installation method for most Windows users. Use **Google Chrome** or **Microsoft Edge**.

<Flag src="/src/assets/pics/logger-build-guide/flash-4a.png" alt="flash 4a">
**Connect the PCB to your computer and turn it on** by pressing and holding the power button on the PCB for about 3 seconds. You can verify that the logger is powered on because a new device will appear in the Device Manager list, under `Ports (COM and LPT)`.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-4.png" alt="flash 4">
Open the Adafruit WebSerial ESPTool here: **[Adafruit WebSerial ESPTool](https://adafruit.github.io/Adafruit_WebSerial_ESPTool/)**. Check the baud rate is set to 115200 and click **Connect**.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-5.png" alt="flash 5">
When Windows shows a list of serial devices, select the port for your BODAQS board and approve access.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-6.png" alt="flash 6">
In the three file rows, **enter the flash addresses** you noted earlier. Click **Choose a file** and select the downloaded BODAQS binary that matches that row's address.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-7.png" alt="flash 7">
Click **Program** and wait for the flash process to complete.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/flash-8_a8.png" alt="flash 8">
If the board does not start automatically after flashing, press the **Reset** button on the board or unplug and reconnect it. (If you are building the logger and flashing firmware for the first time, you can delay this step until the OLED display is installed).
</Flag>

#### Option 2: ESPtool for Mac, Linux, and advanced users

- This option is recommended for Mac and Linux users, and for Windows users who prefer a command-line method.

<Tabs>
  <TabItem label="Via Pip (preferred)">
    <Aside type="note">
      For comprehensive setup for Apple computers see
      [The official installation guide](https://github.com/RavenSystem/esp-homekit-devices/wiki/Install-ESPTool-on-macOS)
    </Aside>
    - Install [Python](https://www.python.org/downloads/) 3.10 or newer if it is not already installed.
    - Install `esptool` by running:

    ```bash
      pip install esptool
    ```
  </TabItem>
  <TabItem label="Via Homebrew (MacOs only)">
    <Aside type="note">
      The homebrew method is a quick way to get `esptool` installed on macOS, but it may not always have the latest version.
      For best results, install via pip
    </Aside>
    If you have Homebrew installed, you can install `esptool` by running:

    ```bash
    brew install esptool
    ```
  </TabItem>
</Tabs>

Once you have your firmware file and ESPtool installed, follow these steps to flash the firmware:

- **Connect your BODAQS board to your computer** with a USB data cable and turn it on, as in Option 1.
{/* //TODO, how to find your port address*/}
- Identify the serial port used by the board:
- **Windows:** something like `COM3`
- **Mac:** something like `/dev/cu.usbmodem...`
- **Linux:** something like `/dev/ttyACM0` or `/dev/ttyUSB0`
- Open a terminal or command prompt in the folder containing the downloaded firmware file.
- Run the following command, replacing the port name and file name as needed:

```bash
esptool --chip esp32s3 --port YOUR_PORT write-flash 0x0 bodaqs-firmware.bin
```

- Example on Windows:

```bash
esptool --chip esp32s3 --port COM3 write-flash 0x0 bodaqs-firmware.bin
```

- Example on Mac or Linux:

```bash
esptool --chip esp32s3 --port /dev/cu.usbmodemXXXX write-flash 0x0 bodaqs-firmware.bin
```

- Wait for the flash process to complete.
- If the board does not start automatically after flashing, press the **Reset** button on the board or unplug and reconnect it.

## If flashing does not work

- Check that your USB cable supports **data**, not just charging.
- Try a different USB port.
- Close any serial monitor or other software that may already be using the serial port.
- Try unplugging and reconnecting the board.
- If needed, restart the board and try again.
- If browser flashing does not work, use the **ESPtool** method instead.

## Preparing the MicroSD card
 
 <Flag src="/src/assets/pics/logger-build-guide/format.png" alt="format">
Connect the MicroSD card to your computer and format it in FAT32.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/config-1.png" alt="config 1">
Create a folder named 'config' in the card's root directory. Download the config file [here](https://github.com/benconnor1972/BODAQS/tree/main/firmware/configs/bodaqs-a8) and place it in the config directory. 
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/config-2.png" alt="config 2">
Open the config file in a text editor and change the timezone to suit your location. The 'tz' parameter requires a POSIX string - you can find a list of them [here](https://github.com/nayarsystems/posix_tz_db/blob/master/zones.csv)
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/config-3.png" alt="config 3">
Add some wifi credentials for one or more WiFi networks (if you plan on running the logger in station mode). You may like to change the logger's SSID and password for Access Point mode too.
</Flag>

<Flag src="/src/assets/pics/logger-build-guide/sd-slot_a8.png" alt="sd slot">
Save the config file and eject the MicroSD card. Install it in the MicroSD slot in the PCB.
</Flag>
