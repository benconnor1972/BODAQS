BODAQS now has its own analysis software. For most applications, we recommend you use it. Alternative workflows include using data.syn.bike for visualization, or for advanced users with a data science bent, Jupyter Lab.   

<MiniAside>
Originally, BODAQS exclusively used an interactive computing platform called **Jupyter Lab** to process, select and visualize logger data. Jupyter Lab is widely used in science, engineering, finance and other quantitative disciplines.

	Jupyter Lab has a distinctive notebook-style way of working that may feel familiar to you if you work in one of those disciplines. For everyone else, it tends to present a bit of a learning curve.

	The reason we made the software this way was that it made it quick and easy to try out new ideas (we still use it for that). But pure notebook-based working is probably best left for power users.

</MiniAside>

## Suggested workflows

Right now there are two ways we recommend doing data analysis with BODAQS:

#### Recommended Workflow: BODAQS Import Manager -> BODAQS Workbench
This is what we recommend for **most users**. It looks like this:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Launch the BODAQS Workbench analysis application. Instructions are [here](/user-guide/analysis-with-workbench/)

#### Alternative 1: BODAQS Import Manager -> data.syn.bike
If you prefer to use syn.bike's visualization tools, you can:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Visit data.syn.bike and upload selected files to visualize them. Instructions are [here](/user-guide/analysis-with-syn-bike/)

#### Alternative 2: BODAQS Import Manager -> Jupyter Lab notebooks 
This workflow is best for power users, Python natives and the extremely curious. It looks like this:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Download, install and set up a Python / Jupyter Lab analysis environment on your computer. Instructions are [here](/software-guide/setup-python-and-jlab/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Use Jupyter Lab notebooks to visualize your data. Instructions are [here](/user-guide/analysis-with-jupyter-lab/)
