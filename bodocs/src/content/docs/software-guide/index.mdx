BODAQS has its own analysis software. For most applications, we recommend you use it. Alternative workflows include using data.syn.bike for visualization, or for advanced users with a data science bent, Jupyter Lab.   

<MiniAside>
Originally, BODAQS exclusively used an interactive computing platform called **Jupyter Lab** to process, select and visualize logger data. Jupyter Lab is widely used in science, engineering, finance and other quantitative disciplines.

	Jupyter Lab has a distinctive notebook-style way of working that may feel familiar to you if you work in one of those disciplines. For everyone else, it tends to present a bit of a learning curve.

	The reason we made the software this way was that it made it quick and easy to try out new ideas (we still use it for that). But pure notebook-based working is probably best left for power users.

</MiniAside>

There are three pieces of BODAQS software. Normally, you install them all at once. When they are packaged together we refer to them as the **BODAQS Desktop**.

#### The BODAQS Import Manager 

<Flag src="/src/assets/pics/software-guide/bike-profile-complete.png" alt="bike profile">
The Import Manager is a program that runs on your computer and handles the import, processing, and storage of your log files. It can semi-automatically download and process files for multiple loggers, either by direct WiFi connection or file drag and drop. Processed files are stored in libraries. Each file source can be configured to write files into a particular library so bikes, riders, events etc can be easily kept separate.
</Flag>

#### The BODAQS Workbench 

<Flag src="/src/assets/pics/homepage/analysis-results.png" alt="analysis results">
The Workbench is a program that lets you visualize and analyze your data. It is a web application so while it will normally run on your computer it can also be hosted on the internet. The Workbench is launched by a button in the Import Manager.
</Flag>

#### The BODAQS Library Service 

<Flag src="/src/assets/pics/software-guide/library-service.png" alt="library service">
The Library Service is normally invisible to users - you will probably never need to concern yourself with it. It starts when the BODAQS Workbench is launched. As the name implies, the Library Service serves data from one or more libraries stored on your computer to the Workbench app. This architecture allows the Workbench to either run locally or be hosted: web browsers can't (and shouldn't) be given free access to your computer's file system.  
</Flag>


## Suggested workflows

Right now there are three ways you can do data analysis with BODAQS:

#### Recommended Workflow: BODAQS Import Manager -> BODAQS Workbench
This is what we recommend for **most users**. It looks like this:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Launch the BODAQS Workbench analysis application. Instructions are [here](/user-guide/analysis-with-workbench/)

#### Alternative 1: BODAQS Import Manager -> data.syn.bike
If you prefer to use syn.bike's visualization tools, you can:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Visit data.syn.bike and upload selected files to visualize them. Instructions are [here](/user-guide/analysis-with-syn-bike/)

#### Alternative 2: BODAQS Import Manager -> Jupyter Lab notebooks 
This workflow is best for power users, Python natives and the extremely curious. It looks like this:
 - Download, install and set up the BODAQS Desktop package. Instructions are [here](/software-guide/setup-import-manager/)
 - Download, install and set up a Python / Jupyter Lab analysis environment on your computer. Instructions are [here](/software-guide/setup-python-and-jlab/)
 - Import files from your logger using the Import Manager. The processed files are stored in a library on your computer.
 - Use Jupyter Lab notebooks to visualize your data. Instructions are [here](/user-guide/analysis-with-jupyter-lab/)
