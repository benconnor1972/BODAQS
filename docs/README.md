# BODAQS Project Documents

This folder contains formal project/reference documents that are useful across
the repository but are not part of the published Astro docs site.

- `analysis/contracts/`: analysis APIs, schemas, artifact contracts, widget
  contracts, and related reference specifications.
- `analysis/notebooks/`: notebook workflow overview material.
- `analysis/release-notes/`: analysis package release notes drafts.
- `analysis/web-app/`: web application roadmap and handoff notes.
- `firmware/`: firmware architecture, release, upload API, and implementation
  notes.
- `interchange/`: cross-project data interchange contracts and examples.

The published documentation site remains in `bodocs/`. Import Manager-specific
docs remain in `import-manager/docs/`.
